## 📌 About the Project

**RideOn** is a web-based vehicle rental platform designed to make renting vehicles simple, convenient, and user-friendly. Users can explore available vehicles, select a suitable ride, and enter their pickup and booking details through an intuitive interface.

The platform supports different vehicle categories, including bikes, scooters, electric bikes, and cars.

## ✨ Key Features

* 🏠 **Home Page** – Clean landing page with navigation and booking options.
* 🏍️ **Vehicle Listings** – Browse available vehicles and rental prices.
* 📅 **Vehicle Booking** – Select a vehicle, pickup location, and rental date.
* 🔐 **User Authentication** – Sign-up and login interface.
* 👤 **User Profiles** – Store user profile information using Supabase.
* 📱 **Responsive Design** – Designed to work across desktop and mobile screens.
* 💰 **Rental Pricing** – Display vehicle rental rates per day.
* 📩 **Contact Section** – Provide contact information and support details.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd RideOn
```

### 3. Configure Supabase

* Create a Supabase project.
* Configure the required database tables and authentication settings.
* Add the appropriate project URL and publishable/anonymous key to your frontend configuration.
* Enable suitable Row Level Security (RLS) policies to protect user data.

**Security note:** Never expose your Supabase service-role key or other secret credentials in frontend code.

### 4. Run the Website

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

If your application uses multiple pages, confirm that all navigation links and file paths work correctly.
